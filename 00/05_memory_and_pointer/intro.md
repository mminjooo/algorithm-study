# 메모리와 포인터
- 128GB RAM (메모리)
- 1 byte 메모리 셀로 이루어짐
- 메모리 셀은 16진수의 고유한 주소를 가짐
- int i라는 4 byte 정수 타입 변수를 선언
    - 선언하면 메모리에 자리를 찜꽁(예약)
    - i에 값을 할당해주면 메모리 셀에 값들이 차곡차곡 저장됨
    - 그렇다면 int i의 주소는? 사용하는 메모리 영역의 첫번째 주소

0x0000  ┐
0x0001  │ int i
0x0002  │
0x0003  ┘
0x0004

# pointer 포인터
- 하위 레벨 c/c++은 가비지컬렉터가 없어 개발자가 직접 필요한 메모리를 예약하고 해제해야 함
- 포인터: 메모리의 주소를 담는 타입
- <타입> *<변수명> = <해당 타입의 변수의 주소>
- *: 에스터리스크 (asterisk)
- int는 4byte, double은 8byte지만 포인터 변수는 상관없이 컴퓨터 운영체제에 따라 고정되어 있음
    - win 64bit = 8byte
    - win 32bit = 4byte

# * 에스터리스크의 역할
1. 곱셈
2. 포인터
3. 역참조 연산자

# dereference operator 역참조 연산자
- a라는 변수
- a의 주소를 담은 포인터 b
- 역참조 연산자를 통해 포인터 b에 담긴 변수를 꺼낼 수 있다

# 배열의 이름을 주소값으로 쓸 수 있다? (array to pointer decay)
```
int a[n];
int *c = a;
```
- int와 int[]는 다른 타입 (정수와 배열)
- 포인터 선언 시 a는 배열인데 int 가능?
    -> array to pointer decay라는 현상이 발생해서 ㄱㅊ
- 배열의 이름(a)을 할당해줄 수 있음
- 할당하면 크기 정보가 날라감 (decay) & a의 첫번째 주소가 바인딩 됨
- 벡터는 불가능 정적 배열만 가능
